networking, network security and Linux through hands-on labs and projects.

I learn by building topologies, breaking them, and troubleshooting why they failed —
then automating the parts worth automating.

**Current focus**

- Python automation for network and security tasks

## Featured Projects

### [CCNA Packet Tracer Labs](https://github.com/abderaoufsec/CCNA-PacketTracerlabs)

Hands-on Cisco Packet Tracer labs following the CCNA curriculum: VLANs and trunking,
routing with OSPF and EIGRP, ACLs, DHCP, NAT, IPv4/IPv6 addressing, VPNs, STP and
basic network security.

### [Networking Labs](https://github.com/abderaoufsec/Networking-Labs)

Broader networking and security labs covering configuration, routing, switching,
services (DHCP, DNS) and network security scenarios.

### [CloudRAG](https://github.com/abderaoufsec/CloudRAG)

Multilingual, local-first Retrieval-Augmented Generation document assistant built as a
full-stack portfolio project — Python, FastAPI, React, FAISS embeddings, local LLMs
and SQLite.

### [myshell](https://github.com/abderaoufsec/myshell)

A UNIX shell implemented in C++, exploring process control, pipes, redirection and
other systems-programming fundamentals.

### [Embedded-iot](https://github.com/abderaoufsec/Embedded-iot)

Embedded and IoT learning track: C programming, electronics, ESP32, sensors, MQTT,
Linux and Raspberry Pi, cloud integration and IoT security.
